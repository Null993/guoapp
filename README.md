# 真果鉴 / 红果鉴

基于 Flutter 的多平台影视应用，支持浏览、搜索、选集、在线播放、下载与备份。站源请求、解析和媒体处理均在设备端完成，不依赖自建服务。

当前发布版本为 **0.2.85+92**，青空本人登录与 Android 实机验收状态见下文。安装包见 [GitHub Releases](https://github.com/Null993/guoapp/releases)。

## 浏览与搜索

- 支持分类、排序、连载状态筛选、榜单、推荐和分页加载。
- 红果支持真人剧、漫剧、AI 剧及搜索联想。
- 全站源搜索随结果返回逐步显示，部分来源失败时保留其他有效结果。
- Windows 分类栏支持鼠标左键拖动、滚轮横移、横向滚轮和触摸拖动。
- 追剧支持想看、在看、已看、有更新等状态；历史记录与播放进度按用户独立保存。

## 播放与下载

- 统一使用 media_kit/mpv，支持选集、续播、多清晰度及备用线路；同清晰度优先 H.264。
- 点击作品直接进入播放页，重复点击去重，返回时取消未完成的详情加载。
- 支持画面缩放、亮度 / 音量手势、快进步长及长按倍速设置；长按倍速可上滑锁定。
- Android 播放期间保持屏幕常亮，硬解失败时可回退软解；无画中画入口。
- Windows 提供画质增强选项；红果在线播放支持弹幕。
- 支持分集下载、批量下载、暂停、继续、重试、删除和补齐缺失分集。
- 宽屏播放页支持选集、简介与下载面板；移动端和电视端使用对应布局。

管理员可恢复已移除的内置站源、移除站源、修改显示名称、单独启停，并导入 / 导出站源目录与更新结果。新增入口用于恢复内置源，不支持任意网址自动适配。

全站源版首次默认显示红果、韩小圈、鬼片、青空。连续点击“最近观看”6 次可打开站源密码锁；设置密码后解锁其他站源，重启重新隐藏。明确选择“不使用密码”后显示全部，已有该设置继续保留。用户权限和站源启停设置分别生效。

单源更新一次启动后持续加载目录并补齐资料。超时、429 / 408 和 5xx 自动退避重试；连续失败 60 分钟后暂停并提供“接着更新”。验证码、认证、保存失败等异常保留已取得进度，并显示相应处理入口。“一键更新”可更新全部已启用站源。

Android 与 Windows 支持程序内登录和验证，提取本站 Cookie、浏览器标识及支持的登录令牌，并保留手工导入入口。站源是否可用、可用画质及 VIP 内容取决于源站、网络和账号权限，应用不解除站点授权限制。

### 青空登录

青空当前播放接口要求登录。在“站源管理 → 青空 → 登录与授权”打开程序内登录页。

- Android 和 Windows 均可在程序内登录本人账号。识别登录令牌后自动返回授权窗口，点击“保存并继续”即可应用；也可点击“登录 / 验证完成”手动提取。
- 提取仅接受当前站点的 HTTPS 页面，Cookie 按对应来源读取，青空令牌与访客标识绑定到青空接口。会话过期后可重新登录。
- 已有本人会话也可手工填入登录令牌、Cookie 和浏览器标识。
- 验证地址保留 `https://api.sorani.cc`。会话仅保留于本次应用运行，关闭后需重新导入；过期时显示登录提示，可重新导入或清除会话。

## 网络与备份

- 网络模式包含自动、直连和手动代理；手动代理支持 HTTP、HTTPS、SOCKS5 / SOCKS5h。
- 自动模式在可恢复网络故障时尝试代理与直连等可用路径，保留具体失败原因。
- 默认校验 TLS 证书；站源凭据按同源限制附带，代理配置不进入备份。
- 剧果、黄果 AI 及相关媒体域名支持 DNS 故障回退，保留原域名与 SNI 并校验 TLS 证书。
- 黄果视频使用官方公布的国内 HTTPS 线路，保留原作品与分集 ID。
- 红果主取流失败时可使用官方 HTTPS 备用接口，保留所选分集与多线路。
- 红果旧接口返回空数据时支持新版官方取流签名与匿名播放身份登记，保留多清晰度及备用线路。
- 支持本地备份、恢复和 WebDAV 手动上传 / 恢复；备份不包含下载的视频。
- 局域网设备可配对、同步追剧和播放进度，并推送接续播放；冲突支持预览和处理。
- 网络与资源设置可调整目录请求并发、请求间隔及下载并发。
